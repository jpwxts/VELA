**How we estimate this**

Each usable 5 km square-day contributes once. Aqua supplies observed activity; calibrated Suomi-NPP contributes only where its required inputs exist. Period totals divide summed activity contributions by summed usable square-days. This is not the percentage of land burned or a wildfire probability.

## Design behavior

The main screen presents activity and daily history together. The map expands on tap on mobile; desktop keeps it beside the answer. Tapping a chart point shows numerator, denominator, usable days and platform contributions, and synchronizes the selected date. Weekly and monthly periods use weighted totals, not averages of percentages. Missing periods remain gaps; observed zero has a visible baseline mark. Future dates have no observed value.

Forecast, dated weather, per-satellite readings, source products, selection rules, model evaluations and processing status remain reachable through their named views or the methods disclosure. No existing data is discarded. Diagram boundaries are schematic; production uses the actual selected map geometry.
