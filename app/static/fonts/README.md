# Fonts

Self-hosted variable fonts from the Adobe Source family, served as WOFF2 (Latin and Latin Extended subsets), downloaded from Google Fonts on 2026-11-14.

| File | Family | Used for |
| --- | --- | --- |
| `source-serif-4-*.woff2` | Source Serif 4 | Place names, pane titles, readings |
| `source-sans-3-*.woff2` | Source Sans 3 | Controls and body text |
| `source-code-pro-*.woff2` | Source Code Pro | Dates, coordinates, measurement labels |

All three are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org), copyright Adobe (http://www.adobe.com/), with Reserved Font Name "Source".
